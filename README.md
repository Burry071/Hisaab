# Hisaab (حساب)

An enterprise-grade, high-whitespace financial intelligence orchestration platform built natively on top of the **Google Antigravity SDK** utilizing an **Android Material 3 Expressive UI** design system.

---

## 1. Executive Project Overview
**Hisaab** acts as an autonomous financial coordinator optimized for modern mobile operating environments. The platform programmatically captures, structures, and audits fragmented, unstructured data signals—such as unformatted banking SMS notifications, digital transaction receipts, and raw manual logs. 

By executing multi-agent pipelines directly on-device, Hisaab eliminates the requirement for heavy centralized cloud parsing, preserving absolute user data privacy and security.

---

## 2. System Architecture & Resilient Data Flow
Hisaab employs a resilient, hybrid-edge computing layout. The architecture is designed to prioritize local hardware processing through Android's native **AICore system daemon**, falling back to secure remote gateways only under constrained runtime or hardware environments.

## 3. Dedicated Agent Topologies

| Agent Identifier | Core Operational Objective | Execution Layer |
| :--- | :--- | :--- |
| **Ingestion Agent** | Normalizes raw, unstructured text arrays into structured cryptographic JSON transaction models. | Local Core / Edge API |
| **Contradiction Agent** | Performs automated double-entry auditing to instantly capture duplicate ledger collisions and sequence errors. | Local Core / Edge API |
| **Forecast Agent** | Compiles expenditure velocity tracking metrics to predict real-time budget depletion horizons. | Local Core / Edge API |
| **Muzzle Proxy Agent** | Zero-trust compliance middleware that strips and redacts sensitive environment tokens from outbound data vectors. | Security Interceptor |

---

## 4. Integration Specifications & API Matrix

### 4.1 On-Device Integration (Antigravity Runtime)
* Targets low-level system execution layers directly via the Antigravity framework.
* Maps multi-turn agent context blocks directly to localized LLM inference lanes via hardware acceleration units.

### 4.2 Production Cloud Fallback (Gemini Developer API)
* Invokes a secure `gemini-2.5-flash` client initialization fallback block when hardware parameters are unmet.
* Enforces structural integrity constraints via strict system instruction injections to guarantee data structures parse cleanly into internal immutable model records.

### 4.3 Low-Level Monospace Audit Trails
Every agent evaluation phase emits real-time runtime outputs directly into an expandable workspace terminal component embedded within the application layout view. This gives engineers and evaluation panels immediate validation tracking access without attaching desktop logs.

## 5. Hardware Verification & Verification Setup
To verify the native on-device machine learning capabilities of the multi-agent system, the target Android smartphone must comply with the following infrastructure metrics:

1. **Compatible Premium Devices:** Google Pixel 8/9/10 series or Samsung Galaxy S24/S25/S26 series devices.
2. **System Configurations:** Operating system packages must be updated to Android 15 or higher (API level 35+).
3. **Developer Flags:** The underlying background compiler flag **"Enable On-Device GenAI Features"** must be manually toggled **`ON`** inside the system Developer Options configuration panel.
